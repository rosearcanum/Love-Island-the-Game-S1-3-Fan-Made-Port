LOVE ISLAND: THE GAME (Seasons 1-3) 

ONE BUTTON: double-click BUILD.bat
It does everything, in order, and only redoes what changed:
  1. converts your downloaded seasons 
  2. shrinks the music
  3. packs all three seasons into the game
  4. builds  Your games\Love Island.exe
  5. builds  Your games\Love Island.apk 

The first run takes a while (about 10-15 minutes). Later runs are much faster.

PLAYING
- PC: copy "Love Island.exe" to any Windows 10/11 PC and double-click it. It's one
  file with everything inside.  Windows may say "Windows protected your PC" the first time: click
  "More info", then "Run anyway".
- Phone: copy "Love Island.apk" to your phone (USB to the Download folder works)
  and tap it to install. Everything is inside the app - no data folder to copy.

SAVES
Kept in your Windows user folder (%APPDATA%\LoveIsland), so replacing or
  moving the exe never loses them. Each PC has its own progress.


PROBLEM REPORT
If the story gets something wrong (wrong partner, a line that looks like
"AJ.2.I.was.wondering.li", someone forgetting what you did), press F9 or use
Menu > Report a problem right there. It copies a report to the clipboard and saves
problem_report.json next to your saves. Paste it to Claude.

Requirements on the PC you build on: Python 3.14 (python.org)

The game contains Fusebox's script and art, so keep these files to your own devices.
